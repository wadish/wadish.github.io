# wadish.github.io

Static portfolio for GitHub Pages. Open `index.html` directly to preview it.

- The home screen shows sales, views, experience since 2019 and two style choices.
- Dark uses brushed metal, rust and sparks. Cute uses pastels, rounded cards, spring motion and stars.
- The selected side is remembered when browser storage is available. Dark shows seven horror games; Cute shows JUST TYPE, Code Nodes and FRAME WORLD. All projects shows the combined catalog, and 3D art is available from either side.
- Experience is calculated as the current calendar year minus 2019; no exact start date is assumed.
- Project cards start with Curse of Beauty (2027), JUST TYPE (2026), then Code Nodes (2026), followed by older projects. Undated 3D artwork follows dated games.
- Header artwork uses a responsive 920:430 frame, without cropping.
- GSAP is bundled locally. The site also works without the animation library and respects reduced-motion preferences.
- Display fonts come from Google Fonts, with system fallbacks.

Run local regression checks with `node verify-redesign.cjs`.

Logo: a custom SVG W with two dots, inspired by the ordinary Unicode letter U+1E84 (W with diaeresis). No enclosing circle.
